# Supplementary material: Multimmit (anonymous submission)

Referee-facing supplementary material for the submission
*Multimmit: faster finality for ordering and payments*.

Contents:

- `communication-supplement.pdf` — *A cubic-communication variant of
  Multimmit*: the dissemination variant referenced in the paper's
  communication-complexity section, achieving O(Kn^2 + n^3) consensus
  communication per logical view. Contains the full construction
  (support certificates, sequential view traversal, erasure-coded
  exact-QC recovery), complete proofs, the transfer of the paper's
  results, and the per-view cost accounting.
- `communication-supplement.tex` — LaTeX source of the above.

Further material (additional supplements and finite-model checking
code) may be added to this repository before the review deadline;
the contents are anonymised throughout.
